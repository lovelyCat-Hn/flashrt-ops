**闭环速度统一律（2026-09-30 实测定案）**：臂速÷数据集原速 = n ÷ (30 × pace × div)，n=每轮步数（spc=n 单指令形态）。pace 下限=推理水位（0.455s，e2e ~390ms），**只许花不许赚**——拉大窗口零收益（推理余量无用处），实测 pace 0.56 轮更差：重规划 2.2→1.75Hz，模型说停时臂多滑 20% 过冲（|Δcmd| 9.3 残差 36.7 签名）。可调的只有 (n, div)。

**工作点定案 v2（2026-10-04，RTC B 脚本当日 14 跑，已写入 config+BUILTIN，取代 9/30 的 20/0.43/1.65）**：`spc=25 / 合步 25 / pace 0.38 / div 1.65 / near_div 2`（≈1.33× 原速），**入口=run_g1_loop_rtc.py（B 变体，推理迟到 hold 兜底）**。四条硬结论：① **pace 低于水位后是死 knob**——0.35/0.38/0.40/0.43 墙钟实测相同（轮节奏钉死在推理水位 ~0.4s/轮），0.38=hold 率与余量折中；9/30 的"0.38 判死/0.40 破位"**只属于 A 脚本深尾路径**，B 脚本 hold 下同档位零垃圾（当日 200+ hold 窗全 |Δcmd|=0，A@0.40 灾难模式绝迹）。② **div 饱和**——spc=25 下 1.45/1.55/1.65 三连复验任务时间零差（14.2/14.5/14.0s），取 1.65=臂最慢 jerk 最小余量最大；9/30"提速正路=动 div"作废。③ **spc 是结构杠杆**——20→25 效应 −2.3s 大于噪声带且被速度律精确命中（预测 14.0 实测 14.2），50 步 chunk 整除成 2 轮/块（20 留 10 步尾巴轮）；spc 30+ 勿试（1.81× 未知区，单指令限幅 ±9 rad）。④ **R 落盒纪录 14.0-14.5s**（数据集 13s，旧工作点 19.7-21s）；spc=25 轮预算落盒 34-46 轮。梦游肥尾：spc20/1.65 一条 R 拖到 t+29s 全程 32.8s（模型侧，执行器无异常）；spc25 三连零梦游——假说"臂追计划更深→执行贴数据时间线→离题窗口小"，3 样本未证。热漂叙事修正：14 连跑 p50 381-394 无单调上漂（9/30"只升不降"被推翻；hold 窗或给 GPU 喘息，未证）。坡升保险丝：B 脚本 `--rtc-ramp N`=hold 连续 ≥2 窗（臂真减速）后 N 轮限速 0.5→1.0 再起步，1 窗早退不触发——健康日零触发（14 跑 0 次），持物/劣化日的 handoff 柔化保险。

**〔9/30 A 脚本时代，史档〕pace 破水位机制 + 六连跑 sweep（定案 pace=0.43，已被 v2 取代）**：pace 压在水位上（实测 ~393ms=推理 384+取图 9，**且随连跑热漂上移 p50 380→394**）时 ±10ms 抖动让每轮在 ~396ms（无续航）↔~800ms（续一条）间抖——等待转进轮内成续航，**续航喂的是旧 chunk 深尾步=计划反转垃圾喂回** → 臂往复 + 夹爪翻摆（梦游同款签名）。sweep 全录：0.38/spc15=全程灾难（往复+疯摆）；0.38/spc20（1.17×）无灾难但 ~30% 轮续航=押注；**0.40 连跑第 3 条被热漂移击穿（尖峰 426ms→过半轮续航+翻摆+500-670 mrad）**；0.42 热态尾段出 2 条续航（尖峰 423）；**0.43/1.65 跑满 59 轮零续航+R 释放单调=当日定案**；0.45/1.47 旧点 51 轮零续航。规律：**pace 下限不是常数，连跑越热越高；A 脚本（无 hold 兜底）选 pace 要按热态水位+35ms 余量**。表头已改诚实（run_g1_loop.py:605）：显示上轮续航条数，"零续航"才健康，破水位一眼可见。另：任务结束轮数 32-49 随跑波动=模型噪声主导，**勿拿单跑轮数选参数**；夹爪 0.15 m/s 六跑全部验证（释放 ~2s、回闭 1-2 轮、R 回闭轮 51→44）。

**div 的物理语义**（--pace-div，2026-09-30 加入，[loop].pace_div 默认 2 零行为变化）：到达时刻 = div×pace；覆盖率 = 1/div；残差 ≈ 导程×(1−1/div)。div=2 窗口在梯形轮廓巡航段正中（全平滑，v4 原设计）；div=1 到点速度过零（停走"一停一停"）；中间值缝落进减速段 → 2.2 Hz 脉动（1.25 明显、1.6 轻微）。div 同时是滞后滤波：chunk 深尾（步 15+ 衰减区）垃圾被衰减 (1−1/div) 后才碰到臂——div 小=忠实执行=摆幅透出，div 大=抹圆但慢。

**工作点〔已被 10-04 v2 取代，史档〕（2026-09-30 六连跑 sweep 终版）**：`spc=20 / 合步 20 / pace 0.43 / div 1.65 / near_div 2 / near_gap 0.06 / speed 1.0 / delta_max 0.3`（≈0.94× 原速；重规划 2.3Hz）。near_div=2 近距阻尼实证：L 释放段干净单调衰减进预松→100% 张开→收爪，无悬停振荡。基线延迟：图模式 ~359ms / eager ~391ms（bench chunk50 bf16）。早段搬运 lunge-hesitate 摆幅（348→55→315 mrad 交替，17 mrad/步 在数据集 p95=147 内）部分是任务真实节奏。**夹爪速度 0.05→0.15 m/s（9/30，六跑全验证）**：数据集释放是 3 帧快开（0.1s），0.05 m/s 把 80mm 开行程拖成 1.6s/爪（纯执行器浪费）；place 任务闭爪只在空爪，无抓物冲击风险。**到位→起释 hover ~1.3s 是训练节奏**（数据集 101 轨本就如此），执行器砍不掉，想砍只能训练侧。~~提速正路=单变量动 div~~（10-04 作废：div 已饱和，结构杠杆是 spc）。

**梦游期铁律**：任务 ≈390 chunk 步（13s×30fps）；rounds 给大后任务结束的模型继续被问就乱挥——签名：R 夹爪 95↔0% 疯摆、300+ mrad 大命令、残差>导程（对动量反向）。**物品落盒立刻 q 停**；rounds ≈ 390/n ×1.3 或手动截断；梦游期日志对配置选型**零判别力**（所有配置的尾巴都是同一副样子，别拿它当证据）。

**双臂任务预算与 q 停修正（2026-09-30）**：only_place 101 轨时间线（action 16 维运动探针）：左臂启动 0.9s → 左爪释放 3.7s（native 6 轮）→ 右臂启动 7.2s = L 释放后 +3.4s（p90 +4.2s）→ 全程 13.5s ≈ native 20 轮；**双臂严格串行（0/101 并行）**。**判别跑已结案（9/30 60 轮全序列走通）**：L 释放 12-15 轮（预测 ~12 死吻合）→ L 回闭 19 → R 释放 37-39 → R 回闭 51，全程 35.9s（≈数据集 2.76×：滞后+静默相位+梦游，**臂速 1.0×≠任务时间线 1.0×**）→ **双臂预算实测 52-60 轮，观察跑 60**；30 轮截断定案（截在 R 启动窗边缘）。**q 停铁律：双臂任务右爪落盒才停**——左爪落盒时右臂还没开始。同轮 graph 闭环首验通过（p50 379.9ms vs eager ~391，60 轮零异常）；上轮释放瞬间的 15s SDK `set_joint_positions` 阻塞（is_blocking=False 仍卡 ~14.5s，主线程卡 SDK C++ 调用有前科）未复现=一次性，若复现考虑夹爪后台线程化。⚠ 判别跑双爪起点 ≈1mm（疑似空爪）——运动/时序/双臂切换验证成立，物理 place 待持物复验。

**chunk 边界语义**（排障速查）：合步**不跨 chunk**——每条指令 100% 属于本 chunk，目标=第 n 步累积增量终点（plan_step(k_end−1)），其余 30 步丢弃；抽帧在第一条指令发出瞬间（k==0，[run_g1_loop.py:630-632]），非步末；spc>steps-per-round 被静默钳到 steps-per-round（[:399]）；**每轮单指令（spc=n）+ 锚永远新鲜 = 无复位解**；spc<n 拆分形态第二条指令啃陈旧锚 → 复位（24/12 实证，弃用）。缝上小幅回追=轨迹弧线的真实内容（关节非单调）+ 25 步前瞻偶发投机过头（496→41 mrad 打脸对），属模型侧，随计划质量改善。

**导航栈 SIGSTOP 搁置杠杆（2026-10-07 实测，BENCHMARKS 附录）**：闭环前 `kill -STOP` 冻结纯导航侧 7 进程（localization/fusion/navigation_plan/vtn/surround/swallows/lidar_capture，PID 随重启变按名找），推理完 `CONT` 原地复活。**vtn 8s 探针实证 launcher 只盯 exit 不怕冻结态**；冻结后 GR3D 50→7%（GPU 争用坐实）、冻结帧推理 375.3→320.5（**−54.8ms，138 的 40%**），叠 W8A16=303.0；loop 外推水位 ~330ms **< pace 380 → 水位击穿**，hold 窗有望清零、pace/spc 恢复灵敏度值得重上探（落盒 14.2→~11s 量级）。**约束**：只在「臂上任务+底盘不动」窗口用（localization 冻结期位姿不更新）；不碰 motion_plan/相机 capture/robot_state_publish/hpu_comm/Perception；真机闭环未验。
